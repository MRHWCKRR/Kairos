# Calendar file export
User accepted date-range .ics download for scheduled tasks and native events, recurrence/term-date/exception parity, imported events excluded by default, private notes excluded. Keep vanilla JS, Firebase ownership, desktop/mobile policy and styles. No dependencies, persistence writes, provider sync, public feed or billing changes.
Approaches: emit recurrence rules (needs a second recurrence engine and complex exception interchange), backend feed (adds access and privacy infrastructure), or concrete local occurrence snapshot. Choose concrete local snapshot, using shared projections, reviewed before local download. No repeated design approval needed within user's go.
UI: Calendars exposes Export schedule. Lazy dialog defaults selected date through30days later, max366 inclusive days; tasks/events enabled, completed tasks and imported events opt-in. Review counts and escaped first50 titles/dates plus omitted-preview count, excluded untimed/invalid-time counts. No download until explicit Download .ics. Inputs/state/timezone changes invalidate review; account/planner switch clears/closes, asynchronous previews generation-guarded. No planner creation or save for export.
Pure buildCalendarExport(state,options) async returns content,filename,rows,counts,omitted. Require ownerId/planId and valid profile timezone/range. At most5000 items and5MiB; reject over budget, never silently truncate. Use monthTaskEntries with prior-day range for overnight work and eventSegmentsForDate to collect complete event occurrences once. Include events intersecting selected dates with their original full time interval. Date-only/untimed tasks omitted with counts; estimated durations use existing Schedule helper. Completed work opt-in. Archived data excluded. Imported events opt-in; warn about duplicate imports. Never include notes, URLs, attendees, alarms, calendar feed links, board/section names or raw account/plan/entity IDs in file.
RFC5545: VCALENDAR VERSION2.0 PRODID; VEVENT UID DTSTAMP DTSTART DTEND SUMMARY CLASS:PRIVATE TRANSP. Timed values UTC using existing zonedTaskStart; invalid DST gaps or nonpositive elapsed intervals omitted with disclosed counts, ambiguous local starts use existing earlier instant. All-day dates use exclusive next-date DTEND. CRLF, text escaping and UTF8-safe75-octet line folding. UIDs SHA256 of owner+plan+kind+sourceid+logical occurrence, stable across range/time changes without exposing raw IDs. Snapshot downloads are not subscriptions; client import duplicate behavior varies.
Tests: parse emitted files with existing ICAL, exactUTC/all-day/end/overnight/DST, recurrence moves/skips/bounds, UID stability, privacy/injection/unicode, filters/range/budgets, stale ownership/download/disposal, browser flow. Independent final review, tests/build/CI, PR ready; hold merge/deploy.
