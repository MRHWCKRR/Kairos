# Weekly event dates
User authorised optional first/last dates for weekly native events, UI/AI parity, projection/planning/reminder consistency and reviewed shortening effects. Inclusive startDate/endDate (YYYY-MM-DD), null/omitted means unlimited. Limits apply to original occurrence date; moved destinations and overnight tails remain intact. Existing series keep unlimited behavior. Imported events remain read-only.
Approaches: destructively prune exceptions (loses user changes), reject shortening until exceptions removed (unnecessary friction), or retain inactive exceptions and disclose them. Choose retention (implementation choice): original dates outside limits are inactive and return on expansion. Review lists newly inactive/reactivated exceptions with original/destination dates; no tasks move. Users can restore an inactive exception to remove its saved override; edits/skips outside limits are rejected.
