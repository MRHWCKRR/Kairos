# Global planner search

Choose **Search** in the sidebar or press **Ctrl/Cmd + K** to find active boards, tasks and assignments within the current planner. Titles, board/section paths, active assignment titles and notes match normalized words. Title matches rank first. All, Unfinished, Overdue and Completed filters use saved completion and dates. For ordinary work, a valid deadline takes precedence over the scheduled date; overdue means before today in the profile timezone. Boards appear only under All. Archived work and ambiguous identities are excluded.

Recurring series remain searchable. Dated results cover original logical dates from 30 days before today to 30 days after today; the dialog explicitly displays this range. Moved occurrences retain their logical identity and show both dates. Skipped/deleted dates are excluded. Filters use occurrence status and displayed date; series are ongoing, never completed or overdue. Up to 50 results are displayed with a total match count and refinement guidance. Search stores no query history and performs no cloud writes, migrations or additional listeners.

The native dialog supports arrows, Enter, Escape, Tab containment and focus restoration. Ctrl/Cmd + K works while typing but does not intercept composition, repeated/alternate modifiers or another open dialog. Selection rechecks availability and closes search before the existing editor requests draft decisions. Failed/cancelled navigation restores the query with feedback. Board results use the workspace Back operation, navigate to Tasks and focus the board card, preserving retained quick-capture drafts.

Authentication changes immediately clear the search ownership stamp and private dialog state before any awaits or early returns. A confirmed plan load/save stamps the verified planner owner; indexing stays gated while a new account loads or loading fails. Account/planner changes clear query, results and filters. Asynchronous navigation checks the captured scope after every preparation step. Assignment metadata is derived only from active unique entries while duplicate checks include archived entries.

Verification covers matching, dates, filters, limits, escaping, native dialog/keyboard interaction, real app authentication-prefix and navigation guards, draft Stay/Discard, board navigation, recurring identity, account races and themes/desktop widths. Browser account/data transport is mocked; the search feature performs no account writes.
