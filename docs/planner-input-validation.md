# Planner input validation

Task commands reject non-string dates and colors, non-persistable input values and malformed supplied recurrence fields before building a save. Repeat edits validate raw interval/count/weekdays/date/mode inputs before normalization; legacy stored rules continue to normalize on reads and unrelated edits. Task estimates accept 1–1440 minutes on both create and edit, while scheduled block durations remain 1–1439 minutes. Existing field-specific UI status paths display these errors and retain drafts.

AI action shape validation now rejects impossible task dates, malformed task times, missing creation titles or reminder lead times, null/oversized titles and inherited object-property action names. Preview and execute call this boundary before accessing planner documents. Existing semantic command checks still run during preview simulation and transaction application. Null and empty schedule values retain their existing unscheduling meaning.

Calendar imports remain atomic. Errors identify the affected event number and, when available, a control-character-stripped title capped at 60 characters. Invalid raw dates name their iCalendar property; malformed RRULE input identifies its event number. Errors from timezone resolution, UID grouping, recurrence expansion and time-range construction retain event context. The import dialog uses plain text for error status and redacts calendar links. A failed refresh does not offer Apply or replace the existing source/events; fix the indicated entry and preview again. Partial imports are deliberately avoided because skipping entries during refresh could delete valid existing commitments.

Coverage includes real shared task commands, AI preview/execute with zero planner reads/writes for rejected requests, mixed valid/invalid calendar parsing and a real parser-to-dialog refresh failure retaining saved data. Standard regression and packaged Chrome persistence journeys remain in CI. This does not establish live Firebase token renewal or operating-system notification delivery.
