# Kairos

Hosted on Cloudflare Workers with Firebase authentication and data storage. Native AI setup and release checks: [native AI guide](docs/native-ai.md).

*Everyone has 24 hours a day. The elite are the elite because time is utilised properly.*

A smart, personalised and practical solution to school/work stress and last minute tasks.
**Kairos** is an AI-assisted smart schedule, allowing you to fit your tasks into an organised and packed day.

---

## Key Features

*   **AI Powered automatic scheduling:** Saves you time and will maximise your time management.
  
*   **AI assistance:** Planning, insights, and chat use OpenRouter through an authenticated Cloudflare API. Users do not supply an API key.
  
*   **Open source with Free and Plus plans:** AI allowances are enforced by the backend. Check the app for current plan availability and pricing.
---

## What its Made Of

*   **Structure:** HTML5
*   **Styling:** CSS3
*   **Logic Engine:** Javascript
*   **Hosting and API:** Cloudflare Workers with Static Assets
*   **Authentication and data:** Firebase Auth, App Check, and Firestore
*   **AI Coordination:** OpenRouter through the same-origin `/api/ai` endpoint
